# Contributing

## Raising Issues

Bug reports and feature requests are welcome via [GitHub Issues](../../issues). Please include:

- Terraform and AWS provider versions
- A minimal reproduction of the problem
- Expected vs actual behaviour

## Pull Requests

This module is not open for unsolicited pull requests. If you've raised an issue and would like to contribute a fix, please wait for a maintainer to confirm the issue and indicate that a PR would be accepted before opening one.

## Version Lifecycle

- `v0.x.x` — module is in development. Interface may change. Not recommended for production use.
- `v1.0.0` — first stable release. Variable interface is considered stable. Safe for production.
- `v1.x.x` onwards — strict semantic versioning applies.
